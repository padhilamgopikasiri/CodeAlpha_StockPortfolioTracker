# CodeAlpha Internship – Task 2: Stock Portfolio Tracker

A console-based Stock Portfolio Tracker in Python. It takes stock names and quantities from the user, calculates the investment using hardcoded stock prices, prints a summary, and saves the report to a text file.

## Features

- Predefined stock prices (AAPL, TSLA, GOOGL)
- Any number of stocks can be entered
- Stock name input is case-insensitive
- Quantity validation (must be greater than 0)
- Handles unknown stock names
- Prints per-stock details and the grand total
- Saves the full report to stock_report.txt

## Files

| File | Description |
|------|-------------|
| StockPortfolio.py | Main Python program |
| stock_report.txt | Sample report generated by the program |

## How to Run

    python StockPortfolio.py

## Concepts Used
